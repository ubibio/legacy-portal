9. 검증 설계

환경변수 경로를 자동 검증하는 테스트를 추가 제안한다. OS 환경변수는 테스트 중 바꾸기 어려우므로, 스프링 SystemEnvironmentPropertySource 를 직접 얹어 "환경변수 이름 형식"이 설정 파일 값을 이기는지 확인한다.

@Test void 운영_설정_파일에_비밀번호_값이_비어_있다()

// 예: 변수는 영어
Map<String, Object> environmentVariables = Map.of("PORTAL_DATASOURCE_URL", UNREACHABLE_MARIADB_URL,
        "PORTAL_DATASOURCE_PASSWORD", "secret");
new ApplicationContextRunner()
    .withInitializer(context -> context.getEnvironment().getPropertySources().addFirst(
        new SystemEnvironmentPropertySource("testEnvironment", environmentVariables)))
    .withPropertyValues("portal.datasource.url=jdbc:mariadb://file-value:3306/portal")
    .withUserConfiguration(DataSourceConfig.class)
    .run(context -> assertThat(output.getOut()).doesNotContain("file-value"));
