요약일정 등록 시 필수값(제목·시작·종료)과 시간 순서를 확인하고, 같은 소유자의 취소(9)되지 않은 일정과 시간이 겹치면 등록을 거부(null 반환)한다. 성공 시 예정(0)으로 저장하고 감사로그 SCHEDULE CREATE를 남긴다. 현재 REST API 는 없고 ScheduleService.create 서비스 메서드만 존재한다.

2. 근거

SRS 없음 (엑셀 F열 · 소스만으로 분석). 아래는 요구사항정의서 F열(상세내용) 원문이다.

[개요]
사용자가 일정을 등록할 때 필수값과 시간 순서를 확인하고, 본인의 다른 일정과 시간이 겹치면 등록하지 않는다.

[상세 기능 요구사항]
1) 제목 · 소유자 ID · 시작 시각 · 종료 시각 · 장소를 받아 일정을 등록한다.
2) 제목이 비었거나, 시작 · 종료 시각이 없거나, 종료가 시작보다 앞서면 등록하지 않는다.
3) 같은 소유자의 취소(9)되지 않은 일정과 시간이 겹치면(시작 < 상대 종료 이고 상대 시작 < 종료) 등록하지 않는다.
4) 등록 직후 상태는 예정(0)이다.
5) 등록 성공 시 감사로그 'SCHEDULE CREATE' 를 남긴다.

[입력 / 출력]
- 입력: 제목, 소유자 ID, 시작 시각, 종료 시각, 장소
- 출력: 등록된 일정 또는 null(등록 거부), 감사로그 1줄

[제약 조건 / 비기능 요구사항]
- 거부 시 null 반환을 유지한다(현재 동작 보존). 거부 사유 응답은 REQ-NF-002 에서 다룬다.
- 종료 시각 = 다른 일정 시작 시각처럼 맞닿는 경우는 겹침으로 보지 않는다.

[검증 기준]
- 10:00~11:00 일정이 있을 때 11:00~12:00 은 등록되고 10:30~11:30 은 거부된다.
- 취소된 일정과 겹치는 시간은 등록된다.
- 종료가 시작보다 앞서면 null 이 반환된다.
