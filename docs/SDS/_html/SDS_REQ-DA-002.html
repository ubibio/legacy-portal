요약시작 시 MariaDB 접속을 확인해 되면 MariaDB, 안 되면 H2 인메모리를 데이터소스로 쓴다(DataSourceConfig). REQ-SE-001 적용으로 접속 정보가 설정 키 · 환경변수로 옮겨졌고, 비밀번호가 비어 있으면 접속을 시도하지 않고 바로 H2 로 간다. H2 선택 시 시작 로그가 F열의 '>> DB = ...' 형식이 아니라 '>> MariaDB 연결 불가 → H2 인메모리로 실행 ...' 이라 문장과 다르다. 또 테스트의 H2 고정은 PORTAL_DATASOURCE_* 환경변수가 없을 때만 보장된다.

2. 근거

[개요] 설치 환경에 따라 MariaDB 가 있으면 MariaDB 를, 없으면 H2 인메모리 DB 를 자동으로 써서 별도 설정 없이 실행된다. [상세 기능 요구사항] 1) 시작 시 localhost:3306/portal 에 2초 제한으로 접속을 시도한다. 2) 접속되면 MariaDB 를, 안 되면 H2 인메모리(jdbc:h2:mem:portal, MODE=LEGACY)를 데이터소스로 쓴다. 3) 어느 DB 를 골랐는지 시작 로그 '>> DB = ...' 로 알린다. 4) H2 사용 시 /h2-console 로 데이터를 조회할 수 있다. 5) 스키마는 JPA ddl-auto=create-drop 으로 만든다. [입력 / 출력] - 입력: 없음(시작 시 접속 시도) - 출력: 데이터소스, 시작 로그 1줄 [제약 조건 / 비기능 요구사항] - 테스트는 항상 H2 인메모리로 돈다. - create-drop 이므로 재시작하면 데이터가 지워진다(교육용 설정).
