진행현황개발중 (비고: 리팩토링 백로그 R13)
요약업무 코드의 LocalDateTime.now() 직접 호출을 주입된 Clock 으로 바꿔 테스트에서 시각을 고정한다. 결재 · 공지 서비스와 감사로그 기록기는 이미 Clock 을 주입받으며(작업 트리에 반영, 아직 미커밋), 운영 소스에 인자 없는 now() 호출이 남아 있지 않다. 일정 서비스만 Clock 을 받지 않는다(현재 시각을 쓰는 곳이 없음). 이 변경은 동작을 바꾸지 않는 리팩토링(숨은 의존성 주입)이다.
