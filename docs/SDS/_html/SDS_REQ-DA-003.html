검토 의견: F열 기능 1 은 '모든 코드에 AttributeConverter' 를 요구하지만, 공지 상태는 특성화 테스트 불변 규칙과 충돌한다. F열을 '공지 상태는 int 저장 + enum 해석(라벨 · 비교)' 으로 보완하거나, 재설계 단계(REQ-NF-002)에서 해당 특성화 테스트를 새 기대값으로 교체하는 별도 커밋 이후에 Converter 를 적용하는 것 중 하나를 선택해야 한다.
