요약현재 서버는 요청 본문의 userId · drafterId 를 그대로 요청자로 믿고, 화면은 localStorage 에 고른 사용자를 저장할 뿐 인증이 없다. 상신은 기안자가 아니어도 된다. 로그인(세션)으로 확인한 사용자를 서버가 요청자로 쓰고, 상신을 기안자 본인으로 제한한다. API 계약(userId 를 본문으로 받음)이 바뀌므로 재설계 단계이며, 이 문서에서 단계적 이행 방식을 정한다. 권한 판정 한 곳(User 메서드)만 충족되어 있다.
