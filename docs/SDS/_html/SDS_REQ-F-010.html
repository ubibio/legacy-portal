[상세 기능 요구사항] 1) 공지 ID 와 요청자 ID 로 게시를 처리한다. 2) 요청자 직급이 팀장(2) 이상이고 공지가 임시(0) 상태일 때만 게시(1)로 바꾼다. 3) 게시된 공지의 분류가 긴급(2)이면 모든 사용자에게 '[긴급공지] {제목}' 메일을 보낸다. 4) 게시 성공 시 감사로그 'NOTICE PUBLISH' 를 남긴다. 5) 상태 표시명: 0=임시, 1=게시, 9=내림, 그 외 '알수없음'. [입력 / 출력] - 입력: 공지 ID, 요청자 ID - 출력: 상태 변경(0→1), 긴급 시 전체 사용자 메일, 감사로그 1줄 [제약 조건 / 비기능 요구사항] - 공지 · 사용자 없음, 권한 없음, 이미 게시됨이면 조용히 무시한다(현재 동작 보존). - 권한 판정은 User.hasNoticePublishAuthority 한 곳에서만 한다. - 현재 게시 내림(9)으로 바꾸는 기능은 없다. [검증 기준] - 사원이 게시하면 상태가 0 으로 남는다. - 긴급 공지 게시 시 사용자 수만큼 메일이 출력되고, 일반 공지는 메일이 없다.
