요약결재 처리 · 공지 게시 · 일정 확정/등록에서 조건이 맞지 않으면 예외 없이 끝나거나(return;) null 을 돌려주는 현재 동작을, 코드 · 메시지를 담은 하나의 오류 응답 형식과 분기별 HTTP 상태(404 · 403 · 409 · 400)로 바꾼다. 현재 소스에는 오류 응답 형식 · 예외 처리기가 전혀 없어 대부분 미충족이며, 이는 외부 관찰 동작을 바꾸는 재설계(리팩토링 아님) 항목이다.
