10. 검토 의견 · 후속 과제

구분내용
보존 대상표시명 문자열 5개 · "알수없음", 등급 문자 S/A/B/C, 경계 '이상(>=)', public 메서드 statusLabel · amountGrade 시그니처와 String 반환.
보존 대상DB 상태값은 정수 code 그대로(@Convert). 정의 밖 code 의 예외 동작.
개선 대상화면(index.html:82-83)이 상태 표시명을 JS 맵으로 따로 가진다 - 서버 enum 과 중복. 라벨을 바꿀 때 두 곳을 고쳐야 한다. 응답에 표시명을 넣는 것은 JSON 계약 변경이라 리팩토링 단계에선 하지 않고 재설계 단계에서 별도 API(예: 코드표 조회)로 검토.
개선 대상statusLabel · amountGrade 를 운영 코드가 쓰지 않는다 - 화면 노출 계획이 없으면 테스트 전용 계약으로 남는다. 업무 확인 후 화면 · API 반영 여부 결정.
개선 대상"상태가 없으면 알수없음" 분기는 사실상 도달 불가(기본값 DRAFT · NOT NULL). 테스트로 고정하거나 재설계 때 정리.
